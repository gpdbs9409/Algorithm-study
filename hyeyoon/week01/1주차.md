# 올바른 괄호

### 유형
자료구조 - Stack

### 가장 어려웠던 부분

괄호 `()`의 짝을 맞추는 문제에 스택을 도입하는 것 자체가 신선했다.

처음 문제를 봤을 때는 단순히 괄호 개수를 세는 방식으로 생각했는데, `(`를 스택에 저장해두고 `)`가 나올 때 하나씩 꺼내면서 짝을 맞추는 방식으로 해결할 수 있었다.

### 새롭게 알게 된 점

처음에는 `)`로 시작하는 경우를 따로 처리하려고 했다.  
예를 들어 첫 번째 문자를 확인하는 `if`문을 별도로 두려고 했는데, 그렇게 하다 보니 예외를 처리하기 위해 코드가 점점 복잡해졌다.

그런데 모든 문자를 순회하면서 `(`가 아닌 경우를 `else`로 처리하고, 그 안에서 `if not stack`을 확인하면 `)`로 시작하는 경우까지 자연스럽게 커버할 수 있었다.

```python
if bracket == '(':
    stack.append(bracket)
else:
    if not stack:
        return False
    stack.pop()
```

따지고 보면 `)`이면서 stack이 비어 있는 경우라는 조건이 걸려 있는데, 중첩 `if` 구조를 사용하면 별도의 예외처리 코드를 만들지 않고 기존 흐름 안에서 처리할 수 있었다.

### 간단한 회고

Stack은 보통 **이전에 들어온 값들을 기억해뒀다가 다시 꺼내야 할 때** 사용하는 자료구조라는 생각이 들었다.

이번 괄호 문제도 결국 이전에 `(`가 들어왔는지를 기억해두는 것이 해결의 키였다.

앞으로 문제를 볼 때 **"직전 값뿐만 아니라, 이전에 들어온 것들을 저장해뒀다가 역순으로 확인해야 하나?"**라는 생각이 들면 Stack을 먼저 떠올려보면 좋을 것 같다.

### 가장 어려웠던 부분

1. 조건이 생각보다 신경 쓸 게 많다.

```python
while right < len(sequence):

    if total == k:
        part.append([left, right])
        total -= sequence[left]
        left += 1
```

에서도 `total == k`이더라도 인덱스를 이동시켜줘야 무한루프가 돌지 않는다. 라던가

```python
elif total < k:
    if right < len(sequence) - 1:
        right += 1
        total += sequence[right]
    else:
        break
```

에서도 `if right < len(sequence) - 1:`의 조건을 넣어주지 않으면 가장 우측의 인덱스에서 `+= 1`하려는 시도가 일어나서 인덱스 에러로 터져버린다.

2. 

```python
if total == k:
    part.append([left, right])
    total -= sequence[left]
    left += 1
```

부분에서 무한루프를 피하기 위해서 `left` 혹은 `right` 인덱스를 이동시켜야했다.
left인 이유는 left를 이동시키면 다음 반복문에서 total<k에 걸리면서 다시 right로.. 앞으로 진행되기 때문이다.
