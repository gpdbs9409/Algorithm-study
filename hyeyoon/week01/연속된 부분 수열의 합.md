
* @문제설명
 * 비내림차순으로 정렬된 수열이 주어질 때, 다음 조건을 만족하는 부분 수열을 찾으려고 합니다.
 * 기존 수열에서 임의의 두 인덱스의 원소와 그 사이의 원소를 모두 포함하는 부분 수열이어야 합니다.
 * 부분 수열의 합은 k입니다.
 * 합이 k인 부분 수열이 여러 개인 경우 길이가 짧은 수열을 찾습니다.
 * 길이가 짧은 수열이 여러 개인 경우 앞쪽(시작 인덱스가 작은)에 나오는 수열을 찾습니다.
 * 수열을 나타내는 정수 배열 sequence와 부분 수열의 합을 나타내는 정수 k가 매개변수로 주어질 때, 위 조건을 만족하는 부분 수열의 시작 인덱스와 마지막 인덱스를 배열에 담아 return 하는 solution 함수를 완성해주세요. 이때 수열의 인덱스는 0부터 시작합니다.
 *
 * 제한사항
 * 5 ≤ sequence의 길이 ≤ 1,000,000
 * 1 ≤ sequence의 원소 ≤ 1,000
 * sequence는 비내림차순으로 정렬되어 있습니다.
 * 5 ≤ k ≤ 1,000,000,000
 * k는 항상 sequence의 부분 수열로 만들 수 있는 값입니다.


### 유형
투포인터



```python
def solution(sequence, k):
    answer = []
    left=0
    right=0
    part=[]
    total=sequence[0]
    partdiff=[]
    while right<len(sequence):
        
        if total==k:
            part.append([left,right])
            total -= sequence[left]
            left+=1
            
        elif total<k:
            if right < len(sequence)-1:
                right+=1
                total+=sequence[right]
            else:
                break
        elif total>k:
            
            total-=sequence[left]
            left+=1
    for i in range(len(part)):
        a,b=part[i]
        partdiff.append([b-a,a,b])
            
    mini=min(partdiff)
    answer=mini[1:3]
    
    return answer
```



### 가장 어려웠던 부분

1. 조건이 생각보다 신경 쓸 게 많다.

```python
while right < len(sequence):

    if total == k:
        part.append([left, right])
        total -= sequence[left]
        left += 1
```

에서도 `total == k`이더라도 인덱스를 이동시켜줘야 무한루프가 돌지 않는다. 라던가

```python
elif total < k:
    if right < len(sequence) - 1:
        right += 1
        total += sequence[right]
    else:
        break
```

에서도 `if right < len(sequence) - 1:`의 조건을 넣어주지 않으면 가장 우측의 인덱스에서 `+= 1`하려는 시도가 일어나서 인덱스 에러로 터져버린다.

2. 

```python
if total == k:
    part.append([left, right])
    total -= sequence[left]
    left += 1
```

부분에서 무한루프를 피하기 위해서 `left` 혹은 `right` 인덱스를 이동시켜야했다.
left인 이유는 left를 이동시키면 다음 반복문에서 total<k에 걸리면서 다시 right로.. 앞으로 진행되기 때문이다. 

### 새롭게 알게 된 점

```python
mini = min(partdiff)
```

`min` 함수는 이차 배열일 경우 배열의 요소들을 순차적으로 비교한다.

원래도 알고 있었지만,

```python
a, b = part[i]
```

구조분해할당이 편한 것 같다.
