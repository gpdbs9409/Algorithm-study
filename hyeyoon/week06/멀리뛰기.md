1. n까지 가는 경우의 수를 구해야 한다.

2. n에 도착하는 마지막 행동은
   1칸 점프 또는 2칸 점프 둘 중 하나다.

3. 마지막에 1칸 뛰었다면
   그 전에는 n-1에 있어야 한다.
   → sol(n-1)의 모든 경우

4. 마지막에 2칸 뛰었다면
   그 전에는 n-2에 있어야 한다.
   → sol(n-2)의 모든 경우

5. 따라서
   sol(n) = sol(n-1) + sol(n-2)

6. 그런데 sol(n-1), sol(n-2)를 재귀로 계속 계산하면
   같은 값을 반복해서 계산한다.

7. 따라서 dp[n]에 한 번 계산한 값을 저장한다.

8. dp[n] == -1일 때만 계산하고,
   이미 값이 있으면 그대로 return한다.

DP를 안썼을때 
    시간복잡도 = 2^N 왜냐하면 n이 계속 그물처럼 두개 경우의 수를 재귀호출하니까 
    공간복잡도 = n (dp배열만큼) , 

풀이 1.
def solution(n):
    dp = [-1] * (n + 1)

    def jump(n):
        if n == 0:
            return 1

        if n == 1:
            return 1

        if dp[n] == -1:
            dp[n] = (jump(n - 1) + jump(n - 2)) % 1234567

        return dp[n]

    return jump(n)

시간복잡도 o(n) 왜냐하면 함수 한번 호출될떄 n만큼의 연산을 한다고 간주되므로.. dp배열의 한 요소마다 한번의 연산을 거친다. =>N 
 공간복잡도 = n (dp배열만큼)
