# 양궁대회 — 백트래킹 학습 진행 기록

## 1) 문제

[프로그래머스 — 양궁대회](https://school.programmers.co.kr/learn/courses/30/lessons/92342)

### 문제 설명

카카오배 양궁대회가 열렸습니다.

라이언은 저번 카카오배 양궁대회 우승자이고 이번 대회에도 결승전까지 올라왔습니다. 결승전 상대는 어피치입니다.

카카오배 양궁대회 운영위원회는 한 선수의 연속 우승보다는 다양한 선수들이 양궁대회에서 우승하기를 원합니다. 따라서, 양궁대회 운영위원회는 결승전 규칙을 전 대회 우승자인 라이언에게 불리하게 다음과 같이 정했습니다.

1. 어피치가 화살 n발을 다 쏜 후에 라이언이 화살 n발을 쏩니다.
2. 점수를 계산합니다.

   - 만약, k(k는 1~10 사이의 자연수)점을 어피치가 a발을 맞혔고 라이언이 b발을 맞혔을 경우 더 많은 화살을 k점에 맞힌 선수가 k점을 가져갑니다.
   - 단, a = b일 경우는 어피치가 k점을 가져갑니다.
   - k점을 여러 발 맞혀도 k점보다 많은 점수를 가져가는 게 아니고 k점만 가져가는 것을 유의하세요.
   - 또한 a = b = 0인 경우, 즉, 라이언과 어피치 모두 k점에 단 하나의 화살도 맞히지 못한 경우는 어느 누구도 k점을 가져가지 않습니다.

   예를 들어, 어피치가 10점을 2발 맞혔고 라이언도 10점을 2발 맞혔을 경우 어피치가 10점을 가져갑니다.

   다른 예로, 어피치가 10점을 0발 맞혔고 라이언이 10점을 2발 맞혔을 경우 라이언이 10점을 가져갑니다.

3. 모든 과녁 점수에 대하여 각 선수의 최종 점수를 계산합니다.
4. 최종 점수가 더 높은 선수를 우승자로 결정합니다. 단, 최종 점수가 같을 경우 어피치를 우승자로 결정합니다.

## 2) 접근 1

### 1. 경우의 수

경우의 수마다 돈다고 생각함. 경우의 수는 라이언의 과녁 배열 조합임. 각 배열의 합은 n이 되어야 함.

그러니까 n을 나눠 먹는 개수가 경우의 수인 거지.

### 1-1. 어떻게 구현할까?

이걸 어떻게 구현할까? 배열로.. 가긴 가는데 첫 번째 요소 → 두 번째 요소 가면서 `-=`로 갱신해 줘야지. 계속 if문으로 10보다 작은지 확인하고..

그러려면 10을 다 넣어야 하니까 너무 많이;; 시간복잡도가 늘어나는데? 그러니까 배열 경우의 수 하나만 채우는 데도 뭐 O(N^2)이 들어가 버림.

### 1-2. 백트래킹을 생각

경우의 수를 따질 때 사실 10을 어떻게 분배하느냐, 이거는 백트래킹으로 가는 게 좋을 것 같긴 함.

왜냐면 설사 최대 경우의 수가 O(n^2)이 나온다고 하더라도 n의 합이 10인데 그 뒤에 배열을 더 보는 것 자체가 낭비이기 때문에, 가지치기 기법을 이용하기 위해서 백트래킹을 생각해 보면 좋을 것 같음.

### 1-3. 백트래킹의 기본 구현

백트래킹의 기본 구현은.. 구현하고 재귀하고 취소하고인데.. (그렇게 하면서 전체 루트를 탐색해야 하니까.)

그러니까 합이 10이 된다면 탐색을 멈추면 되겠지. 이 가지치기는.. ??

---

### 2. 각 경우의 수에서 점수 비교

각 경우의 수마다 for문을 10번 돌리면서 (배열의 개수가 10이므로) 어피치의 총점과 라이언의 총점을 구한 후 비교함.

이때, if문을 이용해서 어피치가 라이언과 동일하면 어피치가 가져가는 경우, 어피치가 가져가는 경우까지 고려해 줘야 함.

### 3. 배열 저장 또는 갱신

경우의 수가 끝나면 라이언이 큰 값으로 이겼을 경우에만 해당 배열을 저장 or 갱신함.

→ 최종 갱신값이 답임.

## 3) sol1

경우의 수를 구하는 백트래킹을 먼저 구현해 보자.

→ 루트를 가면서 재귀에서 누적값을 넘김 (10이 되지 않도록).

### 이 함수에서 구현해야 할 것

1. 루트 따지기 → 각 노드를 넘어가면서 합이 10 이상이 되지 않도록 해야 함.
2. 조건에 맞는 점수를 라이언의 배열에 append해야 함.

lion_score=[0]*11
