# 접근

1. 던전의 방문 순서에 따라 남은 피로도가 달라지고, 그 결과 이후에 방문할 수 있는 던전도 달라진다.

   예를 들어 같은 던전들이 주어져 있어도

   ```text
   A → B → C
   A → C → B
   ```

   처럼 어떤 순서로 방문했는지에 따라 중간에 남아 있는 피로도가 달라진다.

   따라서 단순히 현재 상태만 확인하는 것이 아니라,
   **지금까지 어떤 던전들을 선택해왔는지와 현재 남은 피로도를 함께 고려하면서 여러 방문 순서를 탐색해야 한다.**

2. 이 문제는 **백트래킹**을 이용할 수 있다.

   백트래킹은 가능한 선택을 하나씩 탐색하되,
   현재 선택이 조건에 맞지 않으면 해당 경로는 더 이상 탐색하지 않고 이전 상태로 돌아가 다른 선택을 탐색하는 방식이다.

   이 문제에서는 현재 피로도가 던전의 최소 필요 피로도보다 작다면

   ```python
   fatigue < required
   ```

   해당 던전을 선택하는 경로는 더 진행할 수 없다.

3. 한 던전을 선택했다면 방문 처리한 뒤 다음 던전을 탐색한다.

   ```python
   visited[i] = True
   dfs(fatigue - cost, count + 1)
   ```

   해당 경로의 탐색이 끝나면 이전 상태로 돌아와 방문 처리를 취소한다.

   ```python
   visited[i] = False
   ```

   그래야 같은 던전을 다른 방문 순서에서는 다시 선택할 수 있다.

   ```text
   A 선택
   → B 선택
   → 탐색
   → B 선택 취소
   → C 선택
   → 탐색
   ```

4. 재귀 DFS를 사용하면 함수 호출 정보가 **콜스택(Call Stack)**에 저장된다.

   따라서 현재 경로를 끝까지 탐색한 뒤 이전 호출로 돌아와 상태를 복구하고,
   다른 선택지를 이어서 탐색할 수 있다.

   즉 이 문제의 핵심 흐름은

   ```text
   던전 선택
   → 방문 처리
   → DFS로 다음 선택 탐색
   → 이전 호출로 돌아옴
   → 방문 처리 취소
   → 다른 던전 선택
   ```

   이다.

# sol1

```python
def solution(k, dungeons):
    n = len(dungeons)
    visited = [False] * n

    def dfs(fatigue, count):
        max_count = count

        for i in range(n):
            required, cost = dungeons[i]

            if not visited[i] and fatigue >= required:
                visited[i] = True

                max_count = max(
                    max_count,
                    dfs(fatigue - cost, count + 1)
                )

                visited[i] = False

        return max_count

    return dfs(k, 0)
```

## sol1 풀이

DFS의 인자는

```python
dfs(fatigue, count)
```

로 두었다.

- `fatigue`: 현재 남아 있는 피로도
- `count`: 지금까지 방문한 던전 개수

현재 상태에서 모든 던전을 확인한다.

```python
for i in range(n):
```

아직 방문하지 않았고 현재 피로도로 입장할 수 있다면 해당 던전을 선택한다.

```python
if not visited[i] and fatigue >= required:
```

선택한 던전을 방문 처리하고,

```python
visited[i] = True
```

소모 피로도를 차감한 상태로 다음 DFS를 호출한다.

```python
dfs(fatigue - cost, count + 1)
```

해당 선택으로 시작한 탐색이 끝나면 다시 이전 상태로 돌아온다.

```python
visited[i] = False
```

방문 상태를 복구해야 다른 방문 순서를 탐색할 때 해당 던전을 다시 선택할 수 있다.

가능한 방문 순서를 탐색하면서 얻을 수 있는 최대 던전 수를 `return`한다.
