# 문제

리코쳇 로봇이라는 보드게임이 있습니다.  
이 보드게임은 격자 모양 게임판 위에서 말을 움직이는 게임으로, 시작 위치에서 출발한 뒤 목표 위치에 정확하게 멈추기 위해 최소 몇 번의 이동이 필요한지 말하는 게임입니다.

이 게임에서 말의 이동은 현재 위치에서 상, 하, 좌, 우 중 한 방향으로 게임판 위의 장애물이나 게임판 가장자리에 부딪힐 때까지 미끄러져 움직이는 것을 한 번의 이동으로 정의합니다.

다음은 보드게임판을 나타낸 예시입니다.

- `"."` : 빈 공간
- `"R"` : 로봇의 처음 위치
- `"D"` : 장애물의 위치
- `"G"` : 목표지점

---

# 접근방법

1. 격자 내에서 이동하는 문제이므로 격자 문제의 기본 틀을 생각한다.
   - 상하좌우 정의하기
   - 이동 가능한 거리가 무엇인지 생각하기
   - 탐색 전에 인덱스 범위를 먼저 검사해서 격자를 벗어나지 않도록 하기

2. 격자 문제 + 최소거리이므로 이것도 전형적인 BFS 문제라고 생각했다.  
   이전에 풀었던 Week 4의 1, 2번 문제 풀이와 동일한 방식으로 접근한다.

3. 만약 답이 나오지 않는다면 `return -1`을 꼭 해준다.

```python
from collections import deque

def solution(board):
    # 변수들 정의하기
    row = len(board)
    col = len(board[0])

    dr = [0, 0, 1, -1]
    dc = [1, -1, 0, 0]

    visited = [[False] * col for _ in range(row)]
    sr, sc = 0

    # 시작점 찾기
    for r in range(row):
        for c in range(col):
            if board[row][col] == R:
                sr = row
                sc = col

    queue = deque([(sr, sc, 0)])

    # 탐색 시작
    while queue:
        r, c, distance = queue.popleft()
        visited[r][c] = True

        if boards[r][c] == 'G':
            return distance

        for i in range(4):
            nr = r + dr[i]
            nc = c + dc[i]

            if 0 <= nr < row and 0 <= nc < col and board[r][c] != 'D':
                if visited[nr][nc] == False:
                    queue.append((nr, nc, distance + 1))

    return -1
```

# sol2 - 미끄러짐 아이디어가 틀림

```python
from collections import deque

def solution(board):
    # 변수들 정의하기
    row = len(board)
    col = len(board[0])

    dr = [0, 0, 1, -1]
    dc = [1, -1, 0, 0]

    visited = [[False] * col for _ in range(row)]
    sr, sc = 0

    # 시작점 찾기
    for r in range(row):
        for c in range(col):
            if board[row][col] == R:
                sr = row
                sc = col

    queue = deque([(sr, sc, 0, 0)])
    # 초기 dir을 0으로 넣어도 되는가?
    # 어차피 초기값은 사용되지 않을 것이라고 생각했지만,
    # 실제로는 초기 방향이 우측으로 고정되는 문제가 생김.

    # 탐색 시작
    while queue:
        r, c, distance, dir = queue.popleft()
        visited[r][c] = True

        if boards[r][c] == 'G':
            return distance

        for i in range(4):
            nr = r + dr[i]
            nc = c + dc[i]

            if 0 <= nr < row and 0 <= nc < col and board[r][c] != 'D':
                if visited[nr][nc] == False:
                    if i == dir:
                        queue.append((nr, nc, distance, i))
                    else:
                        queue.append((nr, nc, distance + 1, i))

    return -1
```

## 틀린이유

### 미끄러짐 아이디어

처음에는 다음과 같이 생각했다.

- `for`문으로 4방향을 돌 때 이전 진행 방향과 동일하다면 다른 방향을 탐색하지 않고 그 방향으로 계속 진행한다.
- 이전에 어떤 방향으로 이동했는지 정보가 필요하므로 Queue 안에 직전 이동 방향을 저장한다.
- 방향이 유지되면 `distance`는 그대로 두고, 방향이 바뀌었을 때만 `distance + 1`을 한다.

즉,

```text
Queue에 dir 저장
→ 같은 dir이면 distance 그대로
→ dir이 바뀌면 distance + 1
```

의 방식으로 구현하려고 했다.

하지만 이렇게 하면 초기 `dir` 값을 어떤 방향으로 둘지 애매해진다.  
예를 들어 `dir = 0`으로 두면 첫 이동부터 특정 방향이 이미 선택된 것처럼 처리될 수 있다.

이 문제에서는 직전 방향을 상태로 들고 가는 방식보다, **한 번 방향을 선택하면 해당 방향으로 장애물이나 경계에 닿을 때까지 끝까지 미끄러진 뒤 그 정지 지점을 다음 BFS 노드로 사용하는 방식**이 더 적절하다.
